Six layers, one lock.

Each layer is a built-in macOS, Windows or Chrome mechanism. Nothing patches the system or hides from you.

The enforcer

A root background service that checks everything every 5 seconds. It keeps your account out of the admin group, restores the blocks if anything changes, checks every running app's signature, and runs the unlock timer. A Standard user can't stop it.

Chrome profile

A system configuration profile sets Chrome's URL rules and force-installs the extensions that hide everything but the video, with their settings locked.

Split DNS

YouTube doesn't resolve for any other app on the computer. Chrome alone uses its own encrypted DNS, so it's the only way in, and only to video pages.

Hosts file

Instagram's domains point nowhere for every app on the computer, Chrome included.

App guard

While locked, only apps from developers already on your computer can run. A renamed or re-signed browser is closed on sight.

NextDNS

Optional. Filters DNS on any network you join, encrypted, through the official NextDNS CLI.

Lockbox app

Request an unlock, cancel it, or re-lock early. Admin ends on its own after two hours.

Install in about fifteen minutes.

You need an admin account for setup and Google Chrome. Every step is below.

Install Lockbox

  1. Download and unzip

    Download lockbox-mac.zip and double-click it so a lockbox-mac folder appears in Downloads.

  2. Run the installer

    Open Terminal and paste this. Type your Mac password when asked (nothing shows while you type). It asks for a NextDNS ID: paste yours, or press Enter to skip.

    cd ~/Downloads/lockbox-mac && sudo bash install.sh

Set up Chrome

  1. Install the setup profile

    Open System Settings, then General, then Device Management. Double-click Lockbox – Chrome (setup) and click Install. Then quit Chrome with ⌘Q and open it again. Within a minute uBlock Origin Lite appears in the puzzle-piece menu.

  2. Copy the YouTube filters

    In Terminal:

    pbcopy < /Library/Lockbox/ubol-filters.txt

  3. Paste the filters

    In Chrome, click the puzzle icon, then uBlock Origin Lite, then the gear. Open Custom filters, paste, and save. Open any YouTube video from Google: you should see only the video and its title.

  4. Lock the filters

    Run this, then in Device Management double-click Lockbox – Chrome and click Install. It replaces the setup profile and switches off uBlock's editor. Restart the Mac.

    open /Library/Lockbox/Lockbox-Chrome.mobileconfig

Check and arm

  1. Check every layer

    Every line should have a green tick.

    lockboxctl verify

  2. Arm it

    Keep the apps you use open, then run this with your Mac username. Type ARM to confirm, then restart. From now on your account is a Standard user.

    sudo lockboxctl arm YOUR_USERNAME

Optional: NextDNS

Makes the blocks follow you onto every Wi-Fi network and keeps YouTube out of every app except Chrome. Make a free account at nextdns.io, open the Setup tab and copy the 6-character ID. Paste it when the installer asks, or later (while unlocked):

sudo lockboxctl nextdns YOUR_ID

In the NextDNS dashboard, leave Block Bypass Methods off. It would stop Chrome's own encrypted DNS.

Install Lockbox

  1. Download and unzip

    Download lockbox-windows.zip, right-click it, choose Extract All, and extract it into Downloads.

  2. Run the installer

    Right-click Start and choose Terminal (Admin), then paste this. It asks for a NextDNS ID: paste yours, or press Enter to skip.

    cd $HOME\Downloads\lockbox-windows; powershell -ExecutionPolicy Bypass -File install.ps1

Set up Chrome

  1. Open the filter editor

    Close Terminal and open a new Terminal (Admin), then run this. It also copies the YouTube filters to your clipboard.

    lockboxctl filters open

  2. Paste the filters

    Quit Chrome fully, including from the system tray, and open it again. Click the puzzle icon, then uBlock Origin Lite, then the gear. Open Custom filters, paste, and save. Open any YouTube video from Google: you should see only the video and its title.

  3. Lock the filters

    Then restart Chrome. The Custom filters pane is gone and the filters stay.

    lockboxctl filters lock

Check and arm

  1. Turn on encryption

    Open Settings, then Privacy & security, then Device encryption (or BitLocker on Windows Pro) and turn it on.

  2. Check every layer

    Every line should say OK.

    lockboxctl verify

  3. Arm it

    Keep the apps you use open, then run this with your Windows username. Type ARM to confirm, then sign out and back in. From now on your account is a Standard user.

    lockboxctl arm YOUR_USERNAME

Optional: NextDNS

Makes the blocks follow you onto every network. Make a free account at nextdns.io, open the Setup tab and copy the 6-character ID. Paste it when the installer asks, or later in Terminal (Admin) while unlocked:

lockboxctl nextdns YOUR_ID

In the NextDNS dashboard, leave Block Bypass Methods off. It would stop Chrome's own encrypted DNS.
