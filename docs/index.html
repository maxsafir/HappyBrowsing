Six layers, one lock.

Each layer is a built-in macOS, Windows or Chrome mechanism. Nothing patches the system or hides from you.

The enforcer

A root background service that checks everything every 5 seconds. It keeps your account out of the admin group, restores the blocks if anything changes, checks every running app's signature, and runs the unlock timer. A Standard user can't stop it.

Chrome profile

A system configuration profile sets Chrome's URL rules and force-installs the extensions that hide everything but the video, with their settings locked.

Split DNS

YouTube doesn't resolve for any other app on the computer. Chrome alone uses its own encrypted DNS, so it's the only way in, and only to video pages.

Hosts file

Instagram's domains point nowhere for every app on the computer, Chrome included.

App guard

While locked, only apps from developers already on your computer can run. A renamed or re-signed browser is closed on sight.

NextDNS

Optional. Filters DNS on any network you join, encrypted, through the official NextDNS CLI.

Lockbox app

Request an unlock, cancel it, or re-lock early. Admin ends on its own after two hours.

Install in about ten minutes.

You need an admin account for setup and Google Chrome. NextDNS is optional.

  1. Download and run the installer

    Download lockbox-mac.zip, unzip it into Downloads, then in Terminal. It asks for a NextDNS ID; press Enter to skip.

    cd ~/Downloads/lockbox-mac && sudo bash install.sh

  2. Follow the guide

    It checks what's done and prints the exact next step: approving the Chrome profile, pasting the YouTube filters, then locking them. Run it again after each step.

    lockboxctl guide

  3. Add NextDNS, if you want it

    Shows how to get a free config ID, then sets it up.

    lockboxctl nextdns

  4. Arm it

    This removes your admin rights. Add a wait in minutes to change the 30-minute default.

    sudo lockboxctl arm YOUR_USERNAME

  1. Download and run the installer

    Download lockbox-windows.zip and unzip it into Downloads. Right-click Start, choose Terminal (Admin), then:

    cd $HOME\Downloads\lockbox-windows; powershell -ExecutionPolicy Bypass -File install.ps1

  2. Follow the guide

    In a new admin Terminal. It walks you through pasting the YouTube filters and locking them, then checks every layer.

    lockboxctl guide

  3. Turn on BitLocker or Device encryption

    Without it, someone with a USB stick and physical access could edit files from outside Windows. Settings, then Privacy & security, then Device encryption.

  4. Arm it

    Removes your administrator rights. Sign out and back in afterwards.

    lockboxctl arm YOUR_USERNAME
